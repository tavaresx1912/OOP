# Regras por Checkpoint

## Checkpoint 1 — Fundamentos de Java

**Não é permitido usar:**

❌ Classes personalizadas (ainda não foram abordadas)
❌ Orientação a Objetos: classes com atributos/métodos próprios, herança, polimorfismo, etc. (próximo checkpoint)
❌ Arquivos ou banco de dados (entrada/saída de ficheiros, JDBC, etc.)
❌ Bibliotecas externas (apenas a biblioteca padrão do Java)

**Pode usar:**

✅ Tipos primitivos (int, double, boolean, etc.)
✅ String e seus métodos
✅ Arrays e ArrayList
✅ Estruturas condicionais (if/else, switch)
✅ Estruturas de repetição (for, while, do-while)
✅ Métodos estáticos
✅ Scanner para entrada de dados

---

## Checkpoint 2 — Orientação a Objetos

**Não é permitido usar:**

❌ Modificadores de acesso (ainda não vimos - use padrão)
❌ Getters e Setters formais (próximo checkpoint)
❌ Construtores parametrizados (próximo checkpoint)
❌ Herança, polimorfismo, interfaces (checkpoints futuros)

**Pode usar:**

✅ Classes personalizadas
✅ Atributos de instância
✅ Métodos de instância
✅ Palavra-chave this
✅ ArrayList de objetos
✅ Tudo do CP1 (loops, condicionais, métodos, etc.)

---

## Checkpoint 3 — Encapsulamento e Construtores

**Não é permitido usar:**

❌ Herança, polimorfismo, interfaces (checkpoints futuros)

**Pode usar:**

✅ Modificadores de acesso (private, public, protected)
✅ Getters e Setters
✅ Validações em setters
✅ Construtores (padrão e parametrizados)
✅ Sobrecarga de construtores
✅ this() para chamar outros construtores
✅ Validações em construtores
✅ Tudo dos checkpoints anteriores

---

> Qualquer dúvida sobre o que é permitido num checkpoint específico, consultar o enunciado oficial ou o professor.
